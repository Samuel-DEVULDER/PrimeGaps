# What is this ?
This is recreationnal computing/maths about prime gaps.

[Prime gaps](https://www.pzktupel.de/RecordGaps/gapmainpage.php) is the difference between consecutive prime numbers.

It all started with my answer in a [fr.sci.math thread](https://nemoweb.net/?DataID=3-X5EACLMWPrVwnkqrBOCRb35Ok@jntp).

# Files
Present here are java files aiming at finding gaps.
These are mainly for playing with big numbers and algorithms/implementation.
Don't expect them to break any recent records.
